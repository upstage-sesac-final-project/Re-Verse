# iconTag → iconIndex 매핑 테이블

> LLM은 `iconTag` 문자열을 출력하고, 시스템이 아래 테이블로 `iconIndex` 번호로 변환합니다.
> 이 문서를 수정하면 코드(`asset_generator.py`)에도 동일하게 반영해야 합니다.
>
> **검증 방법**: RPG Maker MZ 에디터 → 아이콘 선택창에서 해당 번호의 아이콘이 맞는지 확인
